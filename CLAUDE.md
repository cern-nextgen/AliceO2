This is the main repository of the ALICE Experiment Simulation, Reconstruction and Analysis Framework.

Skills specific to developing code for this repository can be found in the
`.skills/` folder of this project.

Additional skills and subagents may also exist under `.claude/`
(`.claude/skills/`, `.claude/agents/`) — these are local, not necessarily
committed yet, and separate from the ones in `.skills/`.

For work on `GPU/GPUTracking/SectorTracker` specifically (the `TrackletConstructor`,
`TrackletSelector`, `ExtrapolationTracking` kernels), start with the
`sectortracker-context` skill instead of re-locating source files, thesis
sections, or past findings from scratch.
